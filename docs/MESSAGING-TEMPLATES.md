# תבניות ההודעות ללקוחות: מייל, וואטסאפ ו-PDF (BRD-08)

כל מה שיוצא מ-viper fleet החוצה נראה ונשמע אותו דבר. הכללים באים מ-BRAND.md (§2 קול, §4 צבע, §8
מחוץ לקוד). המסמך מתאר מה בנוי בקוד ומה הבעלים צריכים לאשר אצל הספקים.

## קול

- עברית בגוף שני רבים: "קיבלתם", "שימו לב", "חדשו". לא "הנך", לא "נא", ובלי סימני קריאה.
- משפט אחד שאומר מה קרה, ומשפט אחד שאומר מה לעשות. בלי פתיחה ובלי חתימה ארוכה.
- מספרי רישוי, תאריכים וסכומים כפי שהם מופיעים במערכת (`12-345-67`, `13/11/2026`, `₪750`).

## מייל

נבנה ב-`messaging_email_html` (מיגרציה `20261116190000_branded_email.sql`) לכל מייל שיוצא דרך Resend
או דרך Webhook, לצד הטקסט הרגיל:

- פס navy למעלה עם הלוגו בגרסת reverse (`public/brand-email-logo.png`, נגזר מ-
  `brand/logos/sync-point-midnight-aqua-reverse.png`). הלוגו לא משתנה, לא נמתח ולא מתהפך ב-RTL.
- גוף paper, כרטיס לבן, טקסט ink, תווית `SYNC POINT / ALERT` ב-slate.
- כפתור אחד, aqua עם טקסט ink: "פתיחת viper fleet".
- שורת סיום: למה קיבלתם את ההודעה ואיך מסירים.

כדי שהלוגו והכפתור יופיעו, ממלאים בניהול השירות ← הודעות ← מייל את "כתובת האתר (https)". בלי כתובת
המייל יוצא בלי לוגו ובלי כפתור, אבל עדיין בצבעי המותג.

## וואטסאפ

Meta שולחת הודעות יזומות רק דרך תבנית מאושרת. התבנית מקבלת פרמטר אחד, טקסט ההודעה. זה הנוסח
להגשה לאישור ב-WhatsApp Manager (קטגוריה Utility, שפה he):

```
viper fleet · {{1}}
```

הטקסט שנכנס ל-`{{1}}` נבנה במסד הנתונים. אלה הנוסחים בשימוש היום:

| מה | נוסח |
| --- | --- |
| תוקף מתקרב | `רישיון רכב של 12-345-67 יפוג בעוד 3 ימים (13/11/2026)` |
| תוקף פג היום | `ביטוח חובה של 12-345-67 פג היום` |
| תוקף פג | `רישיון נהיגה של דנה לוי פג לפני יומיים (08/11/2026)` |
| בדיקת ערוץ | `הודעת ניסיון מ-viper fleet: הערוץ מחובר.` |

ההודעות שנשלחות ידנית מהמסכים (קישורי `wa.me`) באות מקבצי התרגום, באותו קול:

| מה | מפתח | נוסח |
| --- | --- | --- |
| קישור מעקב ללקוח (שיגור) | `fleetJobTrackingGreeting`, `fleetJobTrackingEta`, `fleetJobTrackingLink` | `שלום {שם}, הרכב שלנו בדרך אליכם. זמן הגעה משוער: כ-12 דקות. מעקב בזמן אמת: {קישור}` |
| שיתוף רכב | `shareWhatsappText` | `אפשר לעקוב אחרי {רכב} בזמן אמת בקישור: {קישור}` |
| קוד תקלה לנהג | `aiFaultDrive*` | `{רכב}: {תקלה}. לא. לעצור במקום בטוח ולא להמשיך לנסוע.` |

הודעה שלא נכנסת לשורה אחת בטלפון ארוכה מדי. אם צריך יותר, שולחים קישור.

## SMS

אותו טקסט כמו בוואטסאפ, בלי עיצוב. ההודעה נשלחת ב-Unicode, ולכן אורך של עד 70 תווים נכנס בהודעה אחת.

## PDF

כל מסמך שמודפס או נשמר כ-PDF מהדפדפן משתמש ב-`DocumentPrintHeader`
(`src/common/components/print/DocumentPrintHeader.jsx`):

- תווית `SYNC POINT / REPORT`, `SYNC POINT / WORK ORDER` או `SYNC POINT / DRIVER FILE`, כותרת, שורות
  הקשר (תקופה, רכב, ספק, מי הפיק ומתי) והלוגו בגרסת ink, מעל קו ink.
- מספור עמודים `01 / 04` בתחתית כל עמוד (`@page` ב-`public/styles.css`).
- דוחות מודפסים לרוחב A4, ומסמכים (הזמנת עבודה, תיק נהג) לאורך A4.
- תיק הביטוח (SAF-04) נשאר בפורמט משלו, כי הוא נשלח לגורם חיצוני כקובץ אחד.

## מה הבעלים צריכים לעשות

- להגיש את תבנית הוואטסאפ לאישור ב-Meta ולרשום את שמה במסך ההודעות.
- למלא את כתובת האתר בערוץ המייל.
- לאמת את הדומיין של כתובת השולח ב-Resend (SPF ו-DKIM), כדי שהמייל לא יגיע לספאם.
